# Nobreak: Quando o nobreak funciona

Este texto é o mesmo que a janela do Atalaia mostra em **Como conseguir** (Fontes de dados). Se um passo não bate mais com o site, avise numa issue: as telas dos serviços mudam.

## Passo a passo

1. A fonte lê o banco do software de gerenciamento de nobreak da Intelbras. Ele precisa estar instalado e já ter sido aberto uma vez neste PC.
2. O Atalaia só lê esse banco. Não conecta no nobreak nem mexe em nada.
3. Se você tem esse nobreak, ligue a chave ao lado.

## Se der errado

- Banco não encontrado: o software não está instalado ou guarda o banco em outra pasta. Informe o caminho em Plugins:ups:dbPath, no arquivo de configuração.

Na janela, o botão **Testar conexão** confere se o banco do nobreak foi encontrado.
